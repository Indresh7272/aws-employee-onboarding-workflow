# Amazon S3 Static Website Hosting

This folder documents my frontend hosting/deployment contribution.

## Work Performed

- Created a dedicated S3 bucket for the frontend.
- Uploaded the provided static frontend assets.
- Enabled S3 static website hosting.
- Configured the bucket policy required for website access.
- Verified the deployed S3 website endpoint during testing.

## Deployment Pattern

```text
Static frontend files
        |
        v
Amazon S3 bucket
        |
        v
S3 Static Website Endpoint
```

## Important

The frontend application source was developed by another team member, so it is not copied into this personal portfolio repository. This folder documents the AWS hosting work I personally performed.

Real bucket names, URLs, account IDs, and other environment-specific values have been omitted.
